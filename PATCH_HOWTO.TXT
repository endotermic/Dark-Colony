=====================================================================
  DARK COLONY / COUNCIL WARS  -  HOW TO PATCH THE GAME YOURSELF
=====================================================================

This repository ships two kinds of game executables:

  * the UNTOUCHED ORIGINALS from 1997/98 (both games run from the
    "DC - Council wars" folder since 15 Sep 2026)
        DC - Council wars\dc16.exe
        DC - Council wars\ENGEXP16.EXE

  * the PATCHED ones that you normally play
        DC - Council wars\dc16new.exe
        DC - Council wars\engexp16new.exe

  * and the map editor: the original
        Dark Colony - Map editor\maped.exe
    and its unlocked build (the greyed-out dialog controls of the
    original enabled - what the Polish ozi_ns editor did, minus the
    translation)
        Dark Colony - Map editor\maped_ozi_ns_v1.2.exe
    (no CD needed, no CD-drive access, 1024x768, hidden Windows
    pointer, 32 MiB memory pool, 150 % default speed, two-monitor
    fix, ... and for Council Wars the OZI MISSIONS menu)

A hand-modified exe cannot be digitally signed, so some antivirus
programs dislike it and some players do not trust it.  That is why
the repository contains a PATCHING SCRIPT that lets you build the
patched exe yourself, from the original, on your own PC:

        Apply-DarkColonyPatches.ps1     (in the root of the repository)

What makes it trustworthy:

  1) You can carefully investigate the patch content, because it is a
     plain TEXT file.  Open it in Notepad.  Every fix is a list of
     lines like

         @{ Offset = 0x431F; Old = '75'; New = 'EB' }   # jne -> jmp after the CD check

     i.e. "at this position in the file, replace this byte with that
     byte".  Nothing is hidden, nothing is downloaded, no network.

  2) A lot of comments on every step and every line: each fix has a
     description of what it changes in the game and why, and every
     single byte edit has a comment.

  3) The patched executable is ALWAYS created from the original
     executable.  The original file is never modified.  Before a byte
     is written the script checks that the file still holds the
     documented old byte at that position; if anything does not match,
     nothing is written.  After writing it shows the SHA-256 checksum
     of the result - with all fixes selected it is byte-identical to
     the exe published in the repository and the script says so.

  4) Pretty interface and simple usage: a window with a file picker,
     checkboxes for the fixes, a description panel and an Apply
     button.  No Python, no extra tools - only what comes with
     Windows (PowerShell 5.1 or newer).


---------------------------------------------------------------------
  HOWTO
---------------------------------------------------------------------

1) Get the FULL repository from

        https://github.com/endotermic/Dark-Colony

   (green "Code" button -> "Download ZIP", then unpack; or
   "git clone").  You need the whole thing, not just the script:
   the fixes need the game data files that ship next to the exe
   (for example the 1024x768 menus in INTRF_HD\, the Classic movies
   AVI\DCINTRO.AVI etc.).  The script checks for them: a fix whose
   files are not in the target folder is shown as "RESOURCES NOT
   FOUND", cannot be ticked and is left out.

2) Locate the patcher script in the root of the unpacked folder:

        Apply-DarkColonyPatches.ps1

3) Push the RIGHT mouse button on that file to open the submenu.

4) Select  "Run with PowerShell".

   If Windows only flashes a console window and nothing happens,
   script execution is disabled on your PC.  Open a PowerShell
   prompt in the repository folder (Shift + right-click on empty
   space in the folder -> "Open PowerShell window here") and start
   the script once with

        powershell -ExecutionPolicy Bypass -File .\Apply-DarkColonyPatches.ps1

   If Windows shows a security warning about a downloaded file,
   right-click the .ps1 -> Properties -> tick "Unblock" -> OK, then
   try again.

5) Carefully read and follow the instructions in the window to create
   your own patched version of the executable:

   a) "Original exe:"  -> press "Browse..." and pick

          DC - Council wars\dc16.exe               for Dark Colony
          DC - Council wars\ENGEXP16.EXE  for Council Wars
          Dark Colony - Map editor\maped.exe  for the map editor

      The status line tells you which game it is and confirms
      "SHA-256 ... = the untouched original."

   b) "Fixes to apply"  -> tick the fixes you want.  The first box,
      "Select all fixes", ticks every fix; the result is then exactly
      the exe published in the repository.

      Click on a fix to read, in the right-hand panel, what it changes
      and to see its byte edits.  Fixes that only work together are
      listed as such (for example "1024x768 display" needs
      "Interface data from INTRF_HD"); the script refuses to write
      if you select one without the other.

      A fix labelled "[RESOURCES NOT FOUND]" needs data files that
      are not in the folder you write to (the 1024x768 menus in
      INTRF_HD\, the Classic movies AVI\DCINTRO.AVI, DCAENDING.AVI,
      DCHENDING.AVI, the OZI mission pack in ozi_ns\).  It cannot be
      ticked, "Select all fixes" skips it, and the panel says which
      files are missing.  Write the exe into the game folder from the
      repository and the label disappears.

      To get the ORIGINAL 640x480 game that just does not ask for the
      CD, tick only "No CD required" - plus "No CD-drive access" if
      your PC has a card reader, an empty DVD drive or a second hard
      disk as drive D: (otherwise the game still probes that drive at
      every menu and can hang behind a "No Disk" box or stall).

   c) "Write to:"  -> where the patched exe is written.  The default
      is dc16new.exe / engexp16new.exe next to the original, i.e. inside the
      game folder - keep it there, the game needs its data files.  If
      the file already exists the script asks before replacing it.
      It never writes over the original.

   d) Press  "Apply selected fixes".

      The log at the bottom shows how many bytes were written, how
      many fixes were applied and the SHA-256 of the result.  With all
      fixes selected it reads "byte-identical to the exe published in
      the repository".

   e) Start the game with the file you just wrote.

   "Inspect an exe..." checks any Dark Colony executable and tells you
   which build it is and which fixes it already carries - use it on the
   downloaded dc16new.exe / engexp16new.exe if you want to know what is in it.


---------------------------------------------------------------------
  COMMAND LINE (optional, for the record)
---------------------------------------------------------------------

   .\Apply-DarkColonyPatches.ps1 -List                 list the fixes
   .\Apply-DarkColonyPatches.ps1 -List -Detail         ... with every byte edit
   .\Apply-DarkColonyPatches.ps1 -Original "DC - Council wars\dc16.exe" -All
   .\Apply-DarkColonyPatches.ps1 -Original "DC - Council wars\dc16.exe" -Patches cdcheck
   .\Apply-DarkColonyPatches.ps1 -Verify "DC - Council wars\dc16new.exe"

   Patch ids: cdcheck, resolution, cddrive, hdpaths, cursor, pool,
   speed, clock, ddraw, for Dark Colony only movies (the Classic
   intro and endings under their DC* names) and, for Council Wars
   only, ozi.  Map editor:
   blocksets, teams, healer, troopsframe.  -Output sets the target
   file, -Overwrite allows replacing an existing one.


---------------------------------------------------------------------
  WHERE THE PATCHES COME FROM
---------------------------------------------------------------------

   How every fix was found (disassembly, addresses, reasoning) is
   documented in the sister repository

        https://github.com/endotermic/Dark-Colony-Server

   folder docs\ (DC16_DISPLAY_AND_RESOLUTION.md in particular) and the
   Python patch tools in tools\.  The .ps1 script is generated from
   those tools, so it always matches the committed executables.
