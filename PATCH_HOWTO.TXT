=====================================================================
  DARK COLONY / COUNCIL WARS  -  HOW TO PATCH THE GAME YOURSELF
=====================================================================

This repository ships two kinds of executables:

  * the UNTOUCHED ORIGINALS from 1997/98 (both games run from the
    "DC - Council wars" folder since 15 Sep 2026)
        DC - Council wars\dc16.exe              Dark Colony
        DC - Council wars\ENGEXP16.EXE          The Council Wars
        Dark Colony - Map editor\maped.exe      the map editor

  * the PATCHED ones that you normally play (until 25 Sep 2026 they
    were called dc16new.exe, engexp16new.exe, maped_ozi_ns_v1.2.exe)
        DC - Council wars\Dark Colony Ultimate.exe
            (Council Wars plus the Dark Colony, OZI and Academy
            campaigns in its main menu, one LOAD GAME button for the
            saves of all of them, the ONLINE WAR and the
            REPLAY ONLINE GAME buttons)
        Dark Colony - Map editor\Dark Colony Map Editor.exe
            (the greyed-out dialog controls of the original enabled -
            what the Polish ozi_ns editor did, minus the translation)
    (no CD at all, 1024x768 or another resolution, the battlefield
    interface light (classic) or dark (console style), hidden Windows
    pointer, 32 MiB memory pool, 150 % default game speed, two-monitor
    fix, the CD music as MP3, a high-resolution icon, ... and for
    Council Wars the DARK COLONY and OZI MISSIONS menu modes, the
    ONLINE WAR and REPLAY ONLINE GAME buttons)

    The patched Classic "Dark Colony.exe" is DEPRECATED and no longer
    shipped since 1 Oct 2026: Dark Colony Ultimate plays the whole Dark
    Colony campaign, so the separate Classic executable is no longer
    needed.  The patcher still writes it, but only when you ask for it
    (its original dc16.exe stays in the repository).

A hand-modified exe cannot be digitally signed, so some antivirus
programs dislike it and some players do not trust it.  That is why
the repository contains a PATCHING SCRIPT that lets you build the
patched executables yourself, from the originals, on your own PC:

        Apply-DarkColonyPatches.ps1     (in the root of the repository)

and a small starter for it, the file you double-click:

        INSTALL.CMD

What makes it trustworthy:

  1) You can carefully investigate the patch content, because it is a
     plain TEXT file.  Open it in Notepad.  Every fix is a list of
     lines like

         @{ Offset = 0x431F; Old = '75'; New = 'EB' }   # jne -> jmp after the CD check

     i.e. "at this position in the file, replace this byte with that
     byte".  Nothing is hidden, nothing is downloaded, no network.
     (Two fixes append bytes to the exe instead of replacing them:
     the icon appends the icon pictures - the icon itself is
     DC - Council wars\DC_HD.ICO, open it in any image viewer - and,
     for Dark Colony Ultimate, "online" appends the ONLINE WAR /
     REPLAY ONLINE GAME / LOAD GAME module compiled from tools\online\online.c of
     the Dark-Colony-Server repository.  Both are written as Base64
     text with their SHA-256.)

  2) A lot of comments on every step and every line: each fix has a
     description of what it changes in the game and why, and every
     single byte edit has a comment.

  3) The patched executables are ALWAYS created from the original
     executables.  The originals are never modified.  Before a byte
     is written the script checks that the file still holds the
     documented old byte at that position; if anything does not match,
     nothing is written.  After writing it shows the SHA-256 checksum
     of every result - with all fixes selected each is byte-identical
     to the exe published in the repository and the script says so.

  4) Simple usage: an installer window - choose the screen resolution
     and the battlefield interface once, the executables are already
     found and ticked, a summary page, one button.  Checkboxes for
     every fix, a description panel.  No Python, no extra tools - only
     what comes with Windows (Windows PowerShell 5.1, part of Windows
     10 and 11).

  5) The starter INSTALL.CMD is a few lines of text too (open it in
     Notepad): it runs the .ps1 beside it with PowerShell and
     "-ExecutionPolicy Bypass" for that one run, because Windows
     refuses to run a downloaded PowerShell script otherwise.  It
     changes no setting of your PC and installs nothing: the "install"
     is the three patched exes and their desktop shortcuts.


---------------------------------------------------------------------
  HOWTO
---------------------------------------------------------------------

1) Get the FULL repository from

        https://github.com/endotermic/Dark-Colony

   (green "Code" button -> "Download ZIP", then unpack; or
   "git clone").  You need the whole thing, not just the script:
   the fixes need the game data files that ship next to the exe
   (for example the shipped pictures in HD_SRC\<WxH>\, the Classic movies
   AVI\DCINTRO.AVI etc.).  The script checks for them: a fix whose
   files are not in the target folder is shown as "RESOURCES NOT
   FOUND", cannot be ticked and is left out.

2) In the root of the unpacked folder, DOUBLE-CLICK

        INSTALL.CMD

   (Windows may hide the ending: it is the one whose type is
   "Windows Command Script".)  A black console window opens, and a
   moment later the patcher window.  Leave the console open; it
   closes by itself when you close the patcher.

3) If Windows warns about a file from the internet:

   * "Windows protected your PC"  -> click "More info", then
     "Run anyway";
   * "Open File - Security Warning"  -> click "Run".

   To get rid of the warning for good: right-click INSTALL.CMD ->
   Properties -> tick "Unblock" -> OK.

4) If something goes wrong before the window appears, the console
   stays open with the error message and "Press any key to
   continue".  Read it, press a key, and see "IF IT DOES NOT START"
   further down.

5) The installer.  It works like any setup program - pages with
   "< Back", "Next >" and "Cancel" at the bottom.  In the simplest case
   you choose the screen resolution and the battlefield interface,
   press "Next >" through the pages and "Patch" once:

   a) WELCOME.  A greeting, the list of the three originals the script
      found beside itself ("OK" = the untouched original, its SHA-256
      checked):

          Dark Colony Ultimate         DC - Council wars\ENGEXP16.EXE
          Dark Colony Map Editor       Dark Colony - Map editor\maped.exe
          Dark Colony                  DC - Council wars\dc16.exe
                                       (DEPRECATED - only if asked for)

      and the option "Put a shortcut to each patched executable on the
      desktop" (ticked): shortcuts named "Dark Colony Ultimate", "Dark
      Colony Map Editor" (and "Dark Colony" if you patch it), each
      starting in its game folder, where the game finds its files (do
      not copy an exe itself to the desktop).  An older shortcut of the
      same name is replaced.  Press "Next >".

   b) STEP 1 OF 4: OPTIONS.  Three choices, made once for both games
      (they share the interface folder of the chosen size); NOTHING is
      preselected and "Next >" stays disabled until the first two are
      made.  You can come back with "< Back".

      * "Screen resolution" - a drop-down:

          640x480 (original)   - the game as it shipped: no display fix
          1024x768 (4:3)       - the size of the executables published
                                 in the repository
          1280x1024 (5:4), 1280x720 (16:9), 1280x800 (16:10),
          1920x1080 (16:9), 1920x1200 (16:10), 3840x1080 (32:9)

        The sizes with the aspect ratio of your monitor are marked
        "recommended for your screen".  Every size but 640x480 selects
        that size's variant of the display fix and makes the patcher
        WRITE the interface set for it into ITS OWN FOLDER - HD_0768P
        for 1024x768, HD_1080P for 1920x1080, UW_1080P for 3840x1080 ...
        (menus, HUD, briefing lists, letterboxed backgrounds, loading
        screens; a few seconds) - and DELETE the folders of every other
        resolution first (also the INTRF_HD folder of installs patched
        before October 2026), so that no file of another size is left
        anywhere.  The summary page lists what will be deleted.

      * "Battlefield interface" - two radio buttons (live at the HD
        sizes; at 640x480 the game keeps its own interface):

          Light (classic)  - the original brushed-metal battlefield
                             interface: frame, buttons, dialogs and
                             clock dial as the game shipped them
          Dark             - the console style of the menus: grey
                             pipework frame, red-ringed buttons, black
                             dialogs, redrawn clock dial

        Data only, plus one 14-byte fix ("console") that points the
        exe at the redrawn clock dial for the dark interface.  The
        executables published in the repository are the dark 1024x768
        build.

      * "Also patch the deprecated Dark Colony (dc16.exe -> Dark
        Colony.exe)" - unticked.  Dark Colony Ultimate plays the whole
        Dark Colony campaign with every fix, so the separate Classic
        executable is no longer needed and no longer shipped.  Leave
        the box unticked and its page does not appear at all; tick it
        and the installer gets a fourth executable page (STEP 4 OF 5).

   c) STEP 2 OF 4: DARK COLONY ULTIMATE,
      STEP 3 OF 4: DARK COLONY MAP EDITOR
      (and STEP 4 OF 5: DARK COLONY when its box is ticked) - one page
      per executable:

      * "Patch <name>" (ticked) - untick it to leave that executable
        alone.
      * "Original:" the file it is built from, with the status line
        under it, and a "Browse..." button that picks another copy of
        THAT original (for example when the script did not find it).
      * "Screen resolution: ...; battlefield interface: ..." - the
        choices of the options page (the game pages; press "< Back" to
        change them).
      * the fixes of this executable, all ticked, with "Select all
        fixes".  With all fixes the result is exactly the exe published
        in the repository (at 1024x768, dark interface).  Click on a fix to read, in
        the box on the right, what it changes and to see its byte
        edits.  Fixes that only work together are listed as such; the
        script refuses to write if you select one without the other.

        A fix labelled "[RESOURCES NOT FOUND]" needs data files that
        are not in the folder the exe is written to (the Classic movies
        AVI\DCINTRO.AVI, DCAENDING.AVI, DCHENDING.AVI, the OZI mission
        pack in ozi_ns\, the stock INTRFACE\ files the interface set
        is built from).  It cannot be ticked, "Select all fixes" skips
        it, and the box on the right says which files are missing.  Use
        the complete repository and the label disappears.

        To get the ORIGINAL 640x480 game that just does not ask for the
        CD, choose 640x480 (original) on the options page and tick only
        "No CD" (it also stops the game from probing the drive letter
        recorded at install time, so it works on PCs where drive D: is
        a card reader, an empty DVD drive or a second hard disk - the
        original would hang behind a "No Disk" box or stall).
      * "Written to:" where the patched exe goes - always next to its
        original, inside its game folder, where its data files are.  It
        never writes over an original.

      A BIG RED BOX instead of the fixes means the original of that page
      cannot be used: it is missing, it is already patched, it is a
      changed copy (another size or SHA-256 than the original), or it is
      no Dark Colony executable at all.  The Welcome page lists every
      such file in red as well (the deprecated one only when asked
      for).  The box shows
      what was found and what is expected (size and SHA-256), and
      offers:

        * "Select the correct file..." - pick an untouched copy;
        * "Download from our repository" - opens the file's page on
          https://github.com/endotermic/Dark-Colony in your browser
          (the script itself downloads nothing): download it, save it
          under the name and folder the box names, then select it;
        * the original disc: the Council Wars CD has EXPENG\ENGEXP16.EXE
          and the Dark Colony CD has DC\MAPED.EXE, both exactly the
          right files - but NOT dc16.exe: the CD's DC\DC16.EXE is the
          August 1997 build, and the fixes need the January 1998 update
          (659456 bytes), which only the repository has.

      Until the right file is chosen that executable is not patched (its
      "Patch <name>" box is locked); the others can still be.

   d) STEP 4 OF 4 (5 OF 5): READY TO PATCH.  A summary of everything
      that is about to happen - the resolution and the battlefield
      interface, every executable (original ->
      output, how many fixes, which ones were left out and why, whether
      the interface set is written, whether an existing file is
      replaced) or why it is not patched (deprecated and not asked for,
      unticked, no usable original), and the desktop shortcuts.  Nothing has been written
      yet; "< Back" changes anything.  Here "Next >" reads "Patch".

   e) PATCH.  If some of the files already exist the script asks once
      before replacing them.  A small "Patching in progress" box names
      each step: executable by executable, fix by fix, then - for an HD
      resolution - the interface set into its folder (a few seconds).  Then a
      message box and the FINISHED page list every executable: written
      (file, size, SHA-256, "byte-identical to the exe published in the
      repository" with all fixes at 1024x768, dark interface) or failed (what went
      wrong, and that nothing was written), its desktop shortcut, and
      the skipped ones.  Press "Close".

   f) Start the games with the desktop shortcuts, or with the files
      just written.

   "Inspect an exe..." checks any Dark Colony executable and tells you
   which build it is and which fixes it already carries - use it on the
   downloaded "Dark Colony Ultimate.exe" / "Dark Colony.exe" if you want
   to know what is in them.


---------------------------------------------------------------------
  COMMAND LINE (optional, for the record)
---------------------------------------------------------------------

   From a command prompt ("cmd") in the repository folder, through the
   starter:

   INSTALL.CMD -All -Resolution 1024x768 -Theme dark -DesktopShortcut
                       Dark Colony Ultimate and the map editor, like the
                       window; add -IncludeDeprecated for Dark Colony too
   INSTALL.CMD -List                      list the fixes
   INSTALL.CMD -List -Detail              ... with every byte edit
   INSTALL.CMD -Original "DC - Council wars\ENGEXP16.EXE" -All -Resolution 1920x1200 -Theme light
   INSTALL.CMD -Original "DC - Council wars\ENGEXP16.EXE" -Resolution 640x480 -Patches nocd
   INSTALL.CMD -Original "DC - Council wars\dc16.exe" -All -Resolution 1024x768 -Theme dark
                       (the deprecated Classic build, explicitly)
   INSTALL.CMD -Verify "DC - Council wars\Dark Colony Ultimate.exe"

   From a PowerShell prompt write  .\Apply-DarkColonyPatches.ps1  instead
   (after  Set-ExecutionPolicy -Scope Process Bypass  if scripts are
   blocked).  Relative paths are taken from the current folder.

   Patch ids, in the order they are applied:
     both games      nocd,
                     resolution (ONE fix per screen size since 1 Oct
                       2026: the screen mode, the path strings pointing
                       at the size's own interface folder (HD_<height>P,
                       2 Oct 2026) and the clock hand - until then the three fixes
                       resolution, hdpaths, clock; not at 640x480),
                     console (the DARK battlefield interface: the
                       console-style HUD, dialogs and clock dial, data
                       written with the interface set + one 14-byte
                       edit for the dial bank; only with -Theme dark),
                     cursor, pool,
                     speed (150 % default game speed, 10 Sep 2026;
                       dropped 21 Sep, back since 1 Oct 2026; the GAME
                       SPEED slider still changes it in game),
                     ddraw, palette, camera, widemap, restore, longpath,
                     music,
                     menuorder (the menu opens logo, title, buttons,
                       credits instead of buttons first),
                     chat (six battlefield chat lines instead of two,
                       each new line plays the mission-message sound),
                     netsave (no Save Game cell and no F11 save dialog
                       in a network battle, 3 Oct 2026: such a save
                       could never rejoin the relay game)
     Dark Colony     + movies (the Classic intro and endings under
                       their DC* names), sounds (WAV files read from
                       the game root, not from exp\; the Classic
                       briefings)
     Council Wars    + ozi (the DARK COLONY and OZI MISSIONS menu
                       modes)
     map editor      blocksets, teams, healer, troopsframe (the ozi_ns
                       unlocks), then since 1 Oct 2026 race, campaign,
                       medfiles, blockmenu, teamdialogs, lieutenants,
                       artifacts, lights, trigger, aiflags - everything
                       the editor shipped greyed out (aiflags is a dead
                       feature, see its description)
     all three       + icon (the high-resolution icon; for the games also
                       the per-monitor DPI-aware manifest, so Windows never
                       scales the full-screen picture)
     Council Wars    + online, after icon (the ONLINE WAR button: a room
                       browser for the relay server, TLS to port 8889, and
                       the REPLAY ONLINE GAME button: the relay's recorded
                       battles, watched from a participant's seat; the
                       script also writes the screens HD_<height>P\ONLINE
                       and REPLAYE with their backgrounds and, if it is
                       missing, DEFAULT_SERVER.TXT with the fields
                       name=https://github.com/endotermic/Dark-Colony-Server
                       and address=dark-colony-server.fly.dev, shown as the
                       Name: and Server: lines of both screens - a file of
                       the earlier form that still holds only the shipped
                       address is upgraded, an existing file with your own
                       relay address is never overwritten)
   -Resolution WxH picks the screen size and is REQUIRED for the two
   games - there is no default (640x480 = the original size; the
   published exes are 1024x768; -List shows the sizes), -Theme light
   or -Theme dark picks the battlefield interface and is REQUIRED at
   an HD size (the published exes are dark), -Output sets
   the target file (with -Original only), -Overwrite allows replacing
   existing files, -DesktopShortcut adds the desktop shortcuts the
   window's checkbox makes, -IncludeDeprecated makes "-All" without
   -Original patch the deprecated Dark Colony as well.


---------------------------------------------------------------------
  IF IT DOES NOT START
---------------------------------------------------------------------

   * Nothing happens / the console flashes and closes: you probably
     started the .ps1 with "Run with PowerShell".  Windows refuses
     downloaded scripts that way.  Double-click INSTALL.CMD instead.

   * Without the starter: open a PowerShell prompt in the repository
     folder (Shift + right-click on empty space in the folder ->
     "Open PowerShell window here" / "Open in Terminal") and run

        powershell -ExecutionPolicy Bypass -File .\Apply-DarkColonyPatches.ps1

   * "... cannot be loaded because running scripts is disabled" even
     then: your PC is managed (school or company rules).  Play the
     patched exes from the repository: they are the bytes the script
     writes with all fixes at 1024x768, dark interface ("Inspect an exe" / -Verify
     shows it on any PC that can run the script).


---------------------------------------------------------------------
  WHERE THE PATCHES COME FROM
---------------------------------------------------------------------

   How every fix was found (disassembly, addresses, reasoning) is
   documented in the sister repository

        https://github.com/endotermic/Dark-Colony-Server

   folder docs\ (DC16_DISPLAY_AND_RESOLUTION.md in particular) and the
   Python patch tools in tools\.  The .ps1 script is generated from
   those tools, so it always matches the committed executables.
