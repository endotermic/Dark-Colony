=====================================================================
  DARK COLONY / COUNCIL WARS  -  HOW TO PATCH THE GAME YOURSELF
=====================================================================

This file belongs to the INSTALLER PACKAGE - INSTALL.CMD, this file and
the folder patcher\ - published on ModDB and as the repository
Dark-Colony-Ultimate, and carried in the root of the full Dark-Colony
repository as well.  The package holds NOTHING of the game itself: no
original executable, no game data, no music and no patched executable.
The game comes from YOUR two original discs - or is already there when
the package sits in the full Dark-Colony repository (see "HOWTO" 1b);
the installer copies it into a game folder when needed and builds the
patched executables there, on your PC.  The installer knows two
executables:

  * the UNTOUCHED ORIGINALS from 1997/98, taken from your discs
        ENGEXP16.EXE     The Council Wars (EXPENG\ENGEXP16.EXE on the
                         Council Wars CD)
        maped.exe        the map editor (DC\MAPED.EXE on the Dark
                         Colony CD)
    In a disc install they land in the install folder ("Dark Colony"
    in your Documents by default) and its "Map editor" sub-folder; in
    the full Dark-Colony repository they are
        DC - Council wars\ENGEXP16.EXE
        Dark Colony - Map editor\maped.exe
    (that repository also keeps the untouched Classic dc16.exe of
    January 1998, which is not on the discs; the installer does not
    patch it any more - see below)

  * the PATCHED ones that you normally play - written by the installer
    next to their originals, never downloaded (until 25 Sep 2026 they
    were called engexp16new.exe and maped_ozi_ns_v1.2.exe)
        Dark Colony Ultimate.exe
            (Council Wars plus the Dark Colony, OZI and Academy
            campaigns in its main menu, one LOAD GAME button for the
            saves of all of them, the ONLINE WAR and the
            REPLAY ONLINE GAME buttons)
        Dark Colony Map Editor.exe
            (the greyed-out dialog controls of the original enabled -
            what the Polish ozi_ns editor did, minus the translation)
    (no CD at all, 1024x768 or another resolution, the battlefield
    interface light (classic) or dark (console style), hidden Windows
    pointer, 32 MiB memory pool, 150 % default game speed, two-monitor
    fix, the CD music as MP3, a high-resolution icon, no intro movie
    at start-up (DARK COLONY and COUNCIL WARS play their own intro
    when pressed), the DARK COLONY and OZI MISSIONS menu modes, the
    ONLINE WAR and REPLAY ONLINE GAME buttons, ...)

    The patched Classic "Dark Colony.exe" (from dc16.exe) was
    deprecated on 1 Oct 2026 and REMOVED from the installer on 5 Oct
    2026: Dark Colony Ultimate plays the whole Dark Colony campaign
    (DARK COLONY and ACADEMY in its main menu, their saves under LOAD
    GAME), so the separate Classic executable is not needed.

A hand-modified exe cannot be digitally signed, so some antivirus
programs dislike it and some players do not trust it.  That is why
the patched executables are not distributed at all: the repository
contains a PATCHING SCRIPT that builds them, from the originals, on
your own PC:

        patcher\Apply-DarkColonyPatches.ps1

and a small starter for it, the file you double-click:

        INSTALL.CMD     (in the root of the repository)

What makes it trustworthy:

  1) You can carefully investigate the patch content, because it is a
     plain TEXT file.  Open it in Notepad.  Every fix is a list of
     lines like

         @{ Offset = 0x431F; Old = '75'; New = 'EB' }   # jne -> jmp after the CD check

     i.e. "at this position in the file, replace this byte with that
     byte".  Nothing is hidden, nothing is downloaded, no network.
     (Two fixes append bytes to the exe instead of replacing them:
     the icon appends the icon pictures - the icon itself is
     patcher\game\DC_HD.ICO, open it in any image viewer - and, for
     Dark Colony Ultimate, "online" appends the ONLINE WAR / REPLAY
     ONLINE GAME / LOAD GAME module compiled from tools\online\online.c
     of the Dark-Colony-Server repository.  Both are written as Base64
     text with their SHA-256.)

  2) A lot of comments on every step and every line: each fix has a
     description of what it changes in the game and why, and every
     single byte edit has a comment.

  3) The patched executables are ALWAYS created from the original
     executables.  The originals are never modified.  The script first
     checks the SHA-256 of the original, and before a byte is written
     it checks that the file still holds the documented old byte at
     that position; if anything does not match, nothing is written.
     After writing it shows the SHA-256 checksum of every result.  The
     script carries the SHA-256 of the REFERENCE BUILD of every
     resolution and interface (the files the maintainer's tools
     produce); with all fixes selected your result is byte-identical
     to it and the script says so.

  4) Simple usage: an installer window - choose the screen resolution
     and the battlefield interface once, the executables are already
     found and ticked, a summary page, one button.  Checkboxes for
     every fix, a description panel.  No Python, no extra tools - only
     what comes with Windows (Windows PowerShell 5.1, part of Windows
     10 and 11).

  5) The starter INSTALL.CMD is a few lines of text too (open it in
     Notepad): it runs patcher\Apply-DarkColonyPatches.ps1 with
     PowerShell and "-ExecutionPolicy Bypass" for that one run, because
     Windows refuses to run a downloaded PowerShell script otherwise.
     It changes no setting of your PC and installs nothing: the
     "install" is the game folder, the two patched exes, their
     interface data and their desktop shortcuts.

---------------------------------------------------------------------
  HOWTO
---------------------------------------------------------------------

1) Get the installer.  Two ways:

   a) THE INSTALLER PACKAGE - the repository

        https://github.com/endotermic/Dark-Colony-Ultimate

      ("Code" -> "Download ZIP"), or the same package from ModDB.  It
      holds nothing of the game itself.  You need your ORIGINAL DISCS,
      "Dark Colony" and "Dark Colony: The Council Wars" - the CDs in a
      drive, or disc images of them (.iso, .bin with its .cue).  The
      installer copies the game from the discs into a folder of your
      choice ("Dark Colony" in your Documents by default), rips the
      music (both CDs carry the soundtrack as audio tracks 2-5; from a
      .bin / .cue image or a real CD they are ripped and encoded to MP3
      with Windows' own encoder - an .iso holds the data track only, so
      there the music is left out), adds its own files and builds the
      executables there.

   b) THE FULL REPOSITORY from

        https://github.com/endotermic/Dark-Colony

      (green "Code" button -> "Download ZIP", then unpack; or
      "git clone"): the game folder "DC - Council wars", the map
      editor folder "Dark Colony - Map editor" and the same installer
      package (INSTALL.CMD, PATCH_HOWTO.TXT, patcher\).  The game
      folders hold the untouched originals and the game's data, so
      the installer finds everything in place and no discs are needed;
      the copy of patcher\game and patcher\editor changes nothing
      there, the files are already in the game folders.

2) In the root of the unpacked folder, DOUBLE-CLICK

        INSTALL.CMD

   (Windows may hide the ending: it is the one whose type is
   "Windows Command Script".)  A black console window opens, and a
   moment later the patcher window.  Leave the console open; it
   closes by itself when you close the patcher.

3) If Windows warns about a file from the internet:

   * "Windows protected your PC"  -> click "More info", then
     "Run anyway";
   * "Open File - Security Warning"  -> click "Run".

   To get rid of the warning for good: right-click INSTALL.CMD ->
   Properties -> tick "Unblock" -> OK.

4) If something goes wrong before the window appears, the console
   stays open with the error message and "Press any key to
   continue".  Read it, press a key, and see "IF IT DOES NOT START"
   further down.

5) The installer.  It works like any setup program - pages with
   "< Back", "Next >" and "Cancel" at the bottom.  In the simplest case
   you choose the screen resolution and the battlefield interface,
   press "Next >" through the pages and "Patch" once:

   a) WELCOME.  A greeting, the list of the two originals the script
      looks for in the folder above patcher\ ("OK" = the untouched
      original, its SHA-256 checked):

          Dark Colony Ultimate         DC - Council wars\ENGEXP16.EXE
          Dark Colony Map Editor       Dark Colony - Map editor\maped.exe

      (the layout of the full Dark-Colony repository; with the
      installer package on its own the originals come from the discs
      in the next step), the option "Put a shortcut to each patched
      executable on the desktop" (ticked): shortcuts named "Dark
      Colony Ultimate" and "Dark Colony Map Editor", each starting in
      its game folder, where the game finds its files (do not copy an
      exe itself to the desktop); an older shortcut of the same name
      is replaced.  And the checkbox

          "Install the game first, from my original Dark Colony and
           Council Wars discs (no game folder yet)"

      - ticked by itself when no game folder was found beside the
      installer (the installer package on its own).  Ticked, the
      wizard gets the GAME DISCS page below as step 1 and every other
      step moves one down.  Press "Next >".

   a2) STEP 1 OF 5: GAME DISCS (only with the checkbox).  Three rows:

          Council Wars disc   the "Dark Colony: The Council Wars" CD:
                              EXPENG\ENGEXP16.EXE, the expansion, the
                              Classic data it shares
          Dark Colony disc    the original "Dark Colony" CD: the
                              missions, the encyclopedia, the cursors,
                              the briefings, the Classic movies, the
                              map editor
          Install into        a new or empty folder; "Dark Colony" in
                              your Documents by default

      For a disc, "Image file..." picks a disc image (.iso, .bin, .cue)
      and "Drive / folder..." the drive letter of a mounted image or a
      real CD (or a folder holding the disc's files).  Both discs are
      needed; a .bin is read directly, no mounting - and it is the
      .bin / .cue image or the real CD that carries the MUSIC: the four
      audio tracks of each disc are ripped and encoded to MP3 (192
      kbit/s, Windows' own encoder) into MUSIC\ and exp\music\ at the
      Patch step, so the "music" fix has its files.  An .iso image or a
      mounted .iso has no audio tracks; the page then says that the
      music is left out (the "music" fix is then skipped - it needs
      the eight MP3 files, which are not in the package).  "Next >"
      reads the discs, checks that they are the right ones (the
      English Council Wars disc: ENGEXP16.EXE is verified by SHA-256),
      checks the audio tracks and the MP3 encoder, and takes
      ENGEXP16.EXE and maped.exe from them into the install folder
      (maped.exe into its "Map editor" sub-folder); the game itself
      (about 480 MB, some 2260 files) and the music are copied when
      you press "Patch".  Files already in the folder with the right
      size are kept, so an interrupted install can be resumed into the
      same folder.  A wrong disc, a missing file or a disc of another
      language is reported in red on the page, nothing is written.

   b) STEP 1 OF 4 (2 OF 5 with the discs): OPTIONS.  Two choices, made
      once; NOTHING is preselected and "Next >" stays disabled until
      both are made.  You can come back with "< Back".

      * "Screen resolution" - a drop-down:

          640x480 (original)   - the game as it shipped: no display fix
          1024x768 (4:3)       - the size of the reference build
          1280x1024 (5:4), 1280x720 (16:9), 1280x800 (16:10),
          1920x1080 (16:9), 1920x1200 (16:10), 3840x1080 (32:9)

        The sizes with the aspect ratio of your monitor are marked
        "recommended for your screen".  Every size but 640x480 selects
        that size's variant of the display fix and makes the patcher
        WRITE the interface set for it into ITS OWN FOLDER - HD_0768P
        for 1024x768, HD_1080P for 1920x1080, UW_1080P for 3840x1080 ...
        (menus, HUD, briefing lists, letterboxed backgrounds, loading
        screens; a few seconds) - and DELETE the folders of every other
        resolution first (also the INTRF_HD folder of installs patched
        before October 2026), so that no file of another size is left
        anywhere.  The summary page lists what will be deleted.

      * "Battlefield interface" - two radio buttons (live at the HD
        sizes; at 640x480 the game keeps its own interface):

          Light (classic)  - the original brushed-metal battlefield
                             interface: frame, buttons, dialogs and
                             clock dial as the game shipped them
          Dark             - the console style of the menus: grey
                             pipework frame, red-ringed buttons, black
                             dialogs, redrawn clock dial

        Data only, plus one 14-byte fix ("console") that points the
        exe at the redrawn clock dial for the dark interface.  The
        reference build is the dark 1024x768 one; the script knows the
        reference SHA-256 of every size in both interfaces.

   c) STEP 2 OF 4: DARK COLONY ULTIMATE,
      STEP 3 OF 4: DARK COLONY MAP EDITOR
      (one step more each with the discs page) - one page per
      executable:

      * "Patch <name>" (ticked) - untick it to leave that executable
        alone.
      * "Original:" the file it is built from, with the status line
        under it, and a "Browse..." button that picks another copy of
        THAT original (for example when the script did not find it).
      * "Screen resolution: ...; battlefield interface: ..." - the
        choices of the options page (the game page; press "< Back" to
        change them).
      * the fixes of this executable, all ticked, with "Select all
        fixes (result = the reference build)".  Click on a fix to
        read, in the box on the right, what it changes and to see its
        byte edits.  Fixes that only work together are listed as such;
        the script refuses to write if you select one without the
        other.

        A fix labelled "[RESOURCES NOT FOUND]" needs data files that
        are neither in the folder the exe is written to nor in
        patcher\game / patcher\editor.  With this package that is the
        "music" fix when the eight MP3 tracks are missing (an .iso
        image, no encoder), or a fix whose stock game files (the
        INTRFACE\ files the interface set is built from, the exp\
        folder, ...) are missing from an incomplete game folder.  It
        cannot be ticked, "Select all fixes" skips it, and the box on
        the right says which files are missing.

        To get the ORIGINAL 640x480 game that just does not ask for the
        CD, choose 640x480 (original) on the options page and tick only
        "No CD" (it also stops the game from probing the drive letter
        recorded at install time, so it works on PCs where drive D: is
        a card reader, an empty DVD drive or a second hard disk - the
        original would hang behind a "No Disk" box or stall).
      * "Written to:" where the patched exe goes - always next to its
        original, inside its game folder, where its data files are.  It
        never writes over an original.

      A BIG RED BOX instead of the fixes means the original of that page
      cannot be used: it is missing, it is already patched, it is a
      changed copy (another size or SHA-256 than the original), or it is
      no Dark Colony executable at all.  The Welcome page lists every
      such file in red as well.  The box shows
      what was found and what is expected (size and SHA-256), and
      offers:

        * "Select the correct file..." - pick an untouched copy;
        * "Download from our repository" - opens the file's page in the
          full repository https://github.com/endotermic/Dark-Colony in
          your browser (the script itself downloads nothing): download
          it, save it under the name and folder the box names, then
          select it;
        * the original disc: the Council Wars CD has EXPENG\ENGEXP16.EXE
          and the Dark Colony CD has DC\MAPED.EXE, both exactly the
          right files (or tick the disc install on the Welcome page).

      Until the right file is chosen that executable is not patched (its
      "Patch <name>" box is locked); the other can still be.

   d) STEP 4 OF 4 (5 OF 5 with the discs): READY TO PATCH.  A summary
      of everything that is about to happen - the disc install if
      chosen (both discs, the folder, the file count), the resolution
      and the battlefield interface, every executable (original ->
      output, how many fixes, which ones were left out and why, whether
      the interface set is written, whether an existing file is
      replaced) or why it is not patched (unticked, no usable
      original), and the desktop shortcuts.  Nothing has been written
      yet; "< Back" changes anything.  Here "Next >" reads "Patch".

   e) PATCH.  If some of the files already exist the script asks once
      before replacing them.  A small "Patching in progress" box names
      each step: with the discs first the game folder by folder from
      the two discs (half a minute from an image), the eight music
      tracks ripped and encoded (a few seconds each), then for every
      executable the patcher's own files copied into its folder
      (patcher\game -> the game folder, patcher\editor -> the editor's),
      fix by fix, then - for an HD resolution - the interface set into
      its folder (a few seconds).  Then a message box and the FINISHED
      page list every executable: written (file, size, SHA-256,
      "byte-identical to the reference build" when every fix of the
      chosen size and interface went in) or failed (what went wrong,
      and that nothing was written), its desktop shortcut, and the
      skipped ones, and the soundtrack lines ("Dark Colony soundtrack:
      4 of 4 tracks ripped ...").  Without the music (an .iso image, or
      a Windows "N" edition without the Media Feature Pack, which has
      no MP3 encoder) Dark Colony Ultimate gets every fix but "music"
      (21 of its 22 with the dark interface, 20 of 21 with the light
      one) and its line says so instead of "byte-identical".  Press
      "Close".

   f) Start the games with the desktop shortcuts, or with the files
      just written.

   "Inspect an exe..." checks any Dark Colony executable and tells you
   which build it is and which fixes it already carries - use it on an
   exe written earlier, or on one somebody gave you, if you want to
   know what is in it.

---------------------------------------------------------------------
  IF IT DOES NOT START
---------------------------------------------------------------------

   * Nothing happens / the console flashes and closes: you probably
     started the .ps1 with "Run with PowerShell".  Windows refuses
     downloaded scripts that way.  Double-click INSTALL.CMD instead.

   * Without the starter: open a PowerShell prompt in the repository
     folder (Shift + right-click on empty space in the folder ->
     "Open PowerShell window here" / "Open in Terminal") and run

        powershell -ExecutionPolicy Bypass -File .\patcher\Apply-DarkColonyPatches.ps1

   * "the disc reader could not be compiled" / "the GIF reader/writer
     could not be compiled": the script compiles two small C# helpers
     with the .NET compiler that ships with Windows (Add-Type) - a
     managed PC may block that.  For the discs: mount the disc images
     (double-click an .iso) and point the installer at the drive
     letters.  For the interface set there is no way around the
     compiler: the exe is still written, the HD_<height>P folder is
     not - run the installer on a PC where Add-Type works and copy the
     game folder's HD_<height>P, exp\HD_<height>P, dc\HD_<height>P and
     ozi_ns\HD_<height>P folders over.

   * "... cannot be loaded because running scripts is disabled" even
     then: your PC is managed (school or company rules).  There is no
     patched exe to download anywhere, so run the installer on an
     unmanaged PC and copy the written game folder over - "Inspect an
     exe" / -Verify on any PC that can run the script shows what a
     copy carries.


---------------------------------------------------------------------
  WHERE THE PATCHES COME FROM
---------------------------------------------------------------------

   How every fix was found (disassembly, addresses, reasoning) is
   documented in the sister repository

        https://github.com/endotermic/Dark-Colony-Server

   folder docs\ (DC16_DISPLAY_AND_RESOLUTION.md in particular) and the
   Python patch tools in tools\.  The .ps1 script is generated from
   those tools (tools\gen_apply_script.py) by replaying them on the
   originals and diffing after every step, so the reference SHA-256
   values in it are exactly the builds those tools produce.  Which
   file of the game comes from which disc is the list
   tools\disc_manifest.json there (tools\discs.py builds it from the
   two CD images); the installer carries the same list.  This
   repository is refreshed from the two sister repositories with
   tools\publish_installer.py of Dark-Colony-Server.
